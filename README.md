# community-feedback-bot
Telegram-бот для автоматического сбора обратной связи (MVP)

**Роль:** Product / Project Manager, Developer
**Статус:** MVP завершен

## О проекте
Сбор обратной связи в Telegram-сообществах (например, для программы амбассадоров или продуктовых команд) вручную занимает много времени, а важные инсайты пользователей теряются в потоке сообщений. 
Этот бот автоматизирует процесс: он принимает фидбек от пользователей, структурирует его и автоматически выгружает в Google Таблицы для дальнейшего анализа и приоритизации бэклога

## Ценность
- Сокращение времени комьюнити-менеджера на ручной сбор отзывов на 80%
- Сохранение 100% продуктовых гипотез и баг-репортов от пользователей
- Автоматическое формирование базы данных (ответов) в реальном времени

## Стек
- **Python 3**
- **aiogram 3.x** (Асинхронный фреймворк для Telegram API)
- **gspread & Google Sheets API** (Использование таблиц в качестве легковесной БД)
- **python-dotenv** (Безопасность и управление секретами)

## Бэклог на развитие
- Добавить инлайн-кнопки для категоризации фидбека (Жалоба / Идея / Вопрос)
- Интегрировать LLM для сокращения длинных сообщений
- Настроить автоматическую отправку метрик (DAU, количество обращений) в админский чат раз в неделю

## Запуск проекта локально
1. Клонировать репозиторий: `git clone https://github.com/твой-ник/community-feedback-bot.git`
2. Создать виртуальное окружение
3. Установить зависимости: `pip install -r requirements.txt`
4. Добавить токены Telegram и Google API в `.env` и `credentials.json`
5. Запустить
